# SHmap v1.0.5 验收清单

- [ ] 地图图片开关开启后，420%以上精细地图的对象卡可显示图片。
- [ ] 对象存在独立主题主图时，卡片显示该对象的图片，并标记“主题图”。
- [ ] 对象没有独立图片、所在100里地块有主体图时，卡片显示地块图片，并标记“地块图”。
- [ ] 对象图不会被同格地块图覆盖。
- [ ] 点击缩略图打开大图查看器。
- [ ] 点击卡片文字区域仍打开对应对象博物志。
- [ ] 对象和地块都没有图片时保持纯文字卡片，无空白占位图。
- [ ] v1.0.4 冲突内容预览与多选、v1.0.2 图库自动保存等功能继续保留。
- [ ] SQLite、data.js、591个独立对象、617条资料和79段水系均未修改。
