# 山海经原典地图研究台 v1.3.0

## 独立水体流向地图

- 新增独立“水系编辑”工作台：左侧检索与分类水系，中部以山脉和地貌为参照显示河网，右侧集中编辑流向、证据、经篇和区域。
- 支持拖动路径节点、双击河线增加节点、Delete删除节点、反转流向、节点文本精确录入、吸附、撤销、重做和恢复原路径。
- 海、泽、湖、渊、池、沼统一进入水体列表与画布；已有确认面积显示蓝色水域，缺少边界时只显示待核位置。
- 面积水体可从右侧直接进入轮廓编辑器；程序不会按名称自动猜测海域或湖泊边界，只有人工保存后才写入更改记录。
- 保存后写入桌面SQLite工作区并形成 `water_path` 更改记录；重启后不会回到正式种子的旧河线。
- 水系修改可进入原有更改包、三方冲突检查、手动选择、备份和回滚流程。
- V284正式对象、905个占用格和48个权威水流格保持不变；旧82段研究拓扑不会被自动改写。

## 单个合并更新包

- 批量更新优先读取私有仓库 `submissions/bundles/latest.shjbundle`，避免每个 `.shjpatch` 都单独访问一次网络。
- 合并包内部仍按原更改包生成时间逐份模拟、去重和显示冲突，不会把多包压成无法审计的一次覆盖。
- 合并包缺失、损坏或没有覆盖最新更改时，客户端只对缺少部分自动退回原逐包读取。
- 附带 SHmap-Data 合并包生成脚本和 GitHub Actions 模板。

## 私有图片恢复

- `shjasset:` 图片不再通过匿名 raw.github.com 地址读取。
- 登录且通过 SHmap-Data 权限验证后，由桌面端携带当前 GitHub 授权下载。
- 图片保存到应用专用缓存；离线重新打开客户端时仍可显示已缓存图片。
- 文件名和实际 SHA-256 不一致时拒绝缓存，避免错图或损坏图混入。
- 同一张图片只请求一次，失败请求不会在每次重绘时无限重试。
