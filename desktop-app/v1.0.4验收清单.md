# SHmap v1.0.4 验收清单

- [ ] 两台电脑只有导入时间、创建时间或更新时间不同，不再生成需要人工选择的冲突。
- [ ] 冲突卡左侧显示本机地块现有内容，右侧显示更改包拟写入内容。
- [ ] 地块摘要、详细描述、第06节条目、原文、关系和图片资料等真实差异仍会列出。
- [ ] 每条实际内容冲突左侧均有勾选框。
- [ ] “全选本页冲突”能勾选和取消当前页面全部冲突字段。
- [ ] 任意勾选多条后，“所选保留本机”会统一切换这些字段。
- [ ] 任意勾选多条后，“所选采用更改包”会统一切换这些字段。
- [ ] 未勾选的字段保持原来的选择。
- [ ] 应用前仍建立桌面数据库备份，失败时仍恢复应用前状态。
- [ ] v1.0.3 精细地图主题图片、v1.0.2 图库自动保存和此前冲突合并功能均保留。
