# V272 正式地图升级（桌面端代码）

严格依据《山海经原典地图_都广之野核心区_v272_单画布世界地图最终视觉验收冻结.xlsx》。

本包不包含正式地图正文；正式地图正文只上传到 Private `SHmap-Data`。

## 覆盖
将本包内容覆盖到 `F:\SHmap\SHmap\desktop-app\`。

## 然后执行一次
在 `desktop-app` 目录执行：

`node scripts/apply-v272-upgrade.mjs`

该脚本只修改当前的：
- `src-tauri/src/lib.rs`：增加 dataVersion 感知迁移；V125→V272 前自动备份；官方字段严格以V272种子为准，只保留本地 dossier / 子层级 / 图片等补充资料。
- `src/desktop-bootstrap.js`：数据库超时降级时，旧 dataVersion 本地缓存不得覆盖V272私有种子。
- `package.json`：加入 `verify:v272-map`。

然后 Commit / Push，让 Actions 运行。

## 关键冻结
- 正式对象：R9—R632，共624；R633空闲。
- 都广=(0,0)，L1 1格=100里。
- 五卷逐段基线=97091里。
- L2/L3格子不得换算真实里数。
- 四海连续真实岸段=0；外围大陆桥=0。
- 东方 STRONG-0。
- RNG/VIS模型不得升级成真实疆界。
- 121个水系箭头格；英水/洵水/濁浴之水只新增源点首向，不延伸无证河长。
