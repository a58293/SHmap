# SHmap v1.0.0 验收清单

- [ ] 界面、Tauri、Cargo 与运行时均显示 `1.0.0 / v010`。
- [ ] 两台设备给同一对象新增不同图片后，可自动合并为多张图片。
- [ ] 相同图片内容不会重复出现。
- [ ] 两台设备分别修改不同地块内部资料条目时，可自动合并。
- [ ] 仅 `updatedAt` 不同不会显示冲突。
- [ ] 真正冲突逐项显示“保留本机／使用更改包”。
- [ ] 默认选中“保留本机”。
- [ ] 一个冲突不会阻止同包其他安全内容写入。
- [ ] 单包预览和批量更改包使用同一套冲突选择界面。
- [ ] 应用前自动备份；对象、坐标、水系、面积和关系不会被无依据新增。
- [ ] `npm run verify` 与 `cargo check` 通过。
