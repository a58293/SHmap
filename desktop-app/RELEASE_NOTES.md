# 山海经原典地图研究台 v1.1.4

## 本版更新

- 九段式 Markdown 目标匹配升级为三级：正式地图对象 → 已有非空间下属记录 → 父对象第06节“这里有什么”内部子项。
- 文件名如 `洞庭之山.md` 在主地图没有独立对象时，会继续检查所有既有内部子项；唯一命中 `洞庭 → 洞庭之山` 后允许纯文本补充。
- 内部子项接收完整九段式 Markdown 后保存为 `nestedDossier`，可以在子项详情抽屉查看自己的01—09资料与第06节分类条目。
- 子项补充绝不创建新的 R 号、地图对象、地块、坐标、面积、作用域或水系路径。
- 多个父对象存在同名子项时继续阻止自动写入，并提示使用 `父对象（子项名）.md` 消歧。
- 保留 v1.1.3 的水系分类器隔离、普通 Markdown 纯文本策略、跨地图远距离测量和对比两地距离。

# 山海经原典地图研究台 v1.1.3

## 本版更新

- Markdown 导入规则收口：普通 `.md` 仅作为文本／博物志补充，不再因正文或目标名称出现“海、泽、湖、水”等词自动触发面积水域校验。
- 只有“水系分类器”显式生成 `waterTarget / waterBinding` 时，才进入线型水系、面积水域、点状水文的专用校验。
- 测量工具改为“单击起点 → 自由拖动/缩放/搜索/小地图跳转 → 单击终点”，可测超出当前屏幕的远距离。
- 对比面板新增“两地距离”区，2—4 个地块会列出两两直线距离、方向、ΔX、ΔY，并可一键在地图显示测量线。
- 保持 V272 坐标、水系、范围证据与最终水墨背景不变。
