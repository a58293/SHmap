# 山海经原典地图研究台 v1.0.5

## 精细地图对象卡图片回退修正

- 420%以上精细地图卡片优先显示当前对象自己的主题主图。
- 当前对象没有独立主题图时，自动显示它所在100里地块的主体主图，并标记为“地块图”。
- 对象图与地块图均可点击打开现有大图查看器；点击卡片其他区域仍打开对象博物志。
- 对象和地块均无图片时继续保持原来的纯文字卡片，不显示空白占位图。

## v1.0.4

## 冲突只显示地块内容

- 导入时间、创建时间和更新时间属于同步记录，不再列为人工冲突，也不会因为两台电脑时间不同阻止合并。
- 左右对照改为“本机地块现有内容”和“更改包拟写入内容”，对象或档案结构使用直观中文字段展示。
- 实际冲突仍保持逐字段判断，坐标、名称、详细描述、原文、关系、图片说明等真实差异不会被忽略。

## 冲突字段多选

- 每条实际内容冲突增加勾选框。
- 支持全选本页冲突，也可以任意勾选多条。
- 勾选后可一次执行“所选保留本机”或“所选采用更改包”，不再逐条切换下拉框。

## v1.0.3

## 三项功能整合与精细地图图片

- 整合保留 v1.0.1 的冲突内容左右对照与逐字段选择。
- 整合保留 v1.0.2 的图片图库自动保存，添加、删除、主图排序和说明修改均会自动写入。
- 420%以上精细地图的对象预览卡会读取该对象自己的主题主图，并在文字旁显示缩略图。
- 点击预览卡缩略图可打开现有大图查看器；点击卡片其余区域仍打开对象博物志。
- 没有图片的对象继续使用原来的纯文字卡片，不显示空白占位。

## v1.0.2

## 图片图库自动保存

- 添加图片并完成 WebP 转换后立即写入当前地块、对象或内部资料图库，不再依赖手动点击“保存图库”。
- 删除图片、调整主图后立即保存；图片说明、来源和版权备注在停止输入约半秒后自动保存。
- 图库顶部显示“正在保存”“已自动保存”或失败状态，关闭窗口前也会补存尚未写入的修改。
- 重复打开或关闭图库不会产生无内容变化的更改记录。

## v1.0.1

## 冲突内容左右对照

- 冲突窗口不再只显示 `dossier.profile` 等内部字段路径，而是转换为“地块博物志 › 主体档案 › 详细描述”等可读名称。
- 每个冲突字段同时显示“本机当前内容”和“更改包内容”，无需盲选覆盖方式。
- 两边内容使用独立卡片和清晰颜色区分，长文本可在卡片内滚动查看。

## 逐字段选择

- 同一对象内的不同冲突字段可以分别选择保留本机或采用更改包。
- 默认仍保留本机当前内容；只有明确选择后才使用更改包替换该字段。
- 图片、博物志条目及无冲突资料仍继续自动合并，应用前仍会建立备份。

## v1.0.0

## 多端资料自动合并

- 同一对象在不同设备新增不同图片时，按图片内容自动去重并合并，不再把整个图库误判为冲突。
- 地块内部不同资料条目分别新增图片或说明时，按条目名称与分类逐项合并，不再把整个 `dossier` 一起拦截。
- 仅有本机更新时间不同不会再产生虚假冲突。
- 同一图片的说明、来源、版权或主图选择确实被两端改成不同结果时，才列为真正冲突。

## 冲突逐项选择

- 安全内容继续正常应用，不再因为同包中的一项冲突而整包停止。
- 每个真正冲突均可独立选择“保留本机”或“使用更改包”。
- 默认选择“保留本机”，防止无意覆盖本机编辑。
- 单个 GitHub 更改包与批量更改包统一使用相同的合并和冲突选择界面。
- 应用前仍自动建立桌面数据库备份，保存失败时恢复应用前状态。

## v0.9.9

## 顶部与地图工具分层

- 顶部只直接保留导入 Markdown、完成本轮编辑等高频操作，减少连续按钮造成的拥挤。
- 检查数据更新、批量更改包和仅导出更改包统一收进“数据与同步”。
- 地图规格、使用教学和桌面功能统一收进“系统”。
- 关系主题、关系高亮、对比、测量、孤立检查和画笔采集统一收进“地图工具”。
- 地图工具内部按“关系研究、核对工具、采集工具”分组，中等宽度窗口不再挤成多排。

## v0.9.8

## 图片上传卡住修复

- 图片资源改用紧凑 Base64 负载传给桌面端，避免字节数组膨胀造成界面长时间等待。
- GitHub 网络失速会自动停止并给出可重试提示，不再无限卡在“正在提交”。
- 凭据不可用时直接报错，不弹出隐藏的交互窗口；本轮修改和本地导出包始终保留。

## 资料主题图片切换

- 博物志顶部图片改为读取当前选中主题自己的图库主图。
- 切换同一地块内的不同资料主题时，标题、正文和图片同步切换。
- 当前主题没有图片时才回退显示地块主体图；不会再用地块封面覆盖已经上传的主题图片。

## 主题多图图库

- 一个100里地块可分别管理“地块封面”、本格独立对象和第06节内部条目的图片。
- 每个主题支持多张图片，第一张作为卡片主图；可随时设为主图、补充说明与来源或删除单张图片。
- 旧版 `imageUrl` 单图自动作为图库主图沿用，不清空现有图片与资料。
- JPG、PNG、WebP 继续自动缩放并转换为 WebP；图库数组会随 `.shjpatch` 更改包递归打包并跨端同步。
- 图片只改变资料表现，不新增地图对象、坐标、面积、水系或关系。

## v0.9.7

## 批量更改包可选择应用

- 批量检查后会显示真正的逐包勾选框。
- “可应用”和“本机已包含”的安全包默认选中，冲突包默认不选且不可误选。
- 支持一键全选安全包、全部取消和恢复安全推荐。
- 每次改变选择都会按生成时间从旧到新重新模拟所选子集。
- 只有所选子集全部通过时才能应用；未勾选的冲突包不会写入。
- 应用前继续自动建立桌面数据库备份，失败时整批回退。

## 更新说明修正

- 修复程序已经发现新版本，但窗口仍显示旧版说明的问题。
- 仓库直连更新清单兼容旧客户端，v0.9.7 客户端可正确排版 Markdown 说明。
- 发布流程明确使用 UTF-8，避免中文乱码。

## 数据安全

本次升级不覆盖 `data.js`，不清空 SQLite 数据库，也不改变现有对象、坐标、水系路径或区域关系。
