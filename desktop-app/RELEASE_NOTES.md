# 山海经原典地图研究台 v1.0.6

## V272 最终地图基线

- 正式地图以《山海经原典地图_都广之野核心区_v272_单画布世界地图最终视觉验收冻结.xlsx》作为唯一地理位置与世界结构依据。
- 正式对象更新为 R9—R632，共 624 个；R633 继续保留为空号。
- 624 个正式对象全部按 V272《坐标棋盘图》的棋盘位置实装，覆盖 497 个正式占用格。
- L1 中央大陆继续采用 1格=100里；L2 四海与 L3 外围使用 V272 单画布拓扑位置，不再由旧 x/y 自动推格或反算真实里数。
- 东海、南海、西海、北海第一圈及四向外围结构按 V272 棋盘背景层进入客户端。
- 正式 R 号位置锚点不会再被 collection/path/detail/context 资料角色或线型水系显示吞掉。

## 棋盘方向与流向

- 接入 V272《坐标棋盘图》的非 R 号正式表达：背景色带、世界标签与方向格。
- 当前编译包含 368 段棋盘背景色带、8 个世界标签、129 个带方向的棋盘注记。
- “流沙 ← / ↓ / ↙”以及有证据支持的水流、局部方向关系会在客户端地图体现。
- 未明确流向的河流继续不补箭头；L2/L3 未完成正式棋盘路径编译的长河道不会用旧 metric 路径冒充正式河道。
