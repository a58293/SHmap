# 山海经原典地图研究台 v0.9.8

## 图片上传卡住修复

- 图片资源改用紧凑 Base64 负载传给桌面端，避免字节数组膨胀造成界面长时间等待。
- GitHub 网络失速会自动停止并给出可重试提示，不再无限卡在“正在提交”。
- 凭据不可用时直接报错，不弹出隐藏的交互窗口；本轮修改和本地导出包始终保留。

## 资料主题图片切换

- 博物志顶部图片改为读取当前选中主题自己的图库主图。
- 切换同一地块内的不同资料主题时，标题、正文和图片同步切换。
- 当前主题没有图片时才回退显示地块主体图；不会再用地块封面覆盖已经上传的主题图片。

## 主题多图图库

- 一个100里地块可分别管理“地块封面”、本格独立对象和第06节内部条目的图片。
- 每个主题支持多张图片，第一张作为卡片主图；可随时设为主图、补充说明与来源或删除单张图片。
- 旧版 `imageUrl` 单图自动作为图库主图沿用，不清空现有图片与资料。
- JPG、PNG、WebP 继续自动缩放并转换为 WebP；图库数组会随 `.shjpatch` 更改包递归打包并跨端同步。
- 图片只改变资料表现，不新增地图对象、坐标、面积、水系或关系。

## v0.9.7

## 批量更改包可选择应用

- 批量检查后会显示真正的逐包勾选框。
- “可应用”和“本机已包含”的安全包默认选中，冲突包默认不选且不可误选。
- 支持一键全选安全包、全部取消和恢复安全推荐。
- 每次改变选择都会按生成时间从旧到新重新模拟所选子集。
- 只有所选子集全部通过时才能应用；未勾选的冲突包不会写入。
- 应用前继续自动建立桌面数据库备份，失败时整批回退。

## 更新说明修正

- 修复程序已经发现新版本，但窗口仍显示旧版说明的问题。
- 仓库直连更新清单兼容旧客户端，v0.9.7 客户端可正确排版 Markdown 说明。
- 发布流程明确使用 UTF-8，避免中文乱码。

## 数据安全

本次升级不覆盖 `data.js`，不清空 SQLite 数据库，也不改变现有对象、坐标、水系路径或区域关系。
