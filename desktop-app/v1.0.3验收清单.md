# SHmap v1.0.3 验收清单

- [ ] 放大到420%以上，悬停或点开精细对象组，有主题图片的对象卡在文字旁显示自己的主图。
- [ ] 同一地块多个对象分别有图时，每张对象卡只显示自身图库主图，不串用兄弟主题图片。
- [ ] 点击缩略图打开大图查看器，关闭后仍停留在当前精细地图位置。
- [ ] 点击卡片的名称或文字区域仍打开对应对象博物志。
- [ ] 没有图片的对象卡保持纯文字布局，不显示空白图片框。
- [ ] 对象图库更换主图并自动保存后，重新进入精细地图会显示新主图。
- [ ] 冲突内容左右对照与逐字段选择仍可使用。
- [ ] 图库添加、删除、主图排序和图片说明修改仍会自动保存。
- [ ] SQLite、data.js、617条基础资料、79段水系路径和118个箭头格均未改动。
