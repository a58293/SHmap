# SHmap v1.2.0 / V282 升级与发布顺序

## 原因

v1.1.7 的空白地图不是数据丢失，而是启动迁移在模块初始化期间提前调用了后置比较器，触发 JavaScript TDZ 异常。v1.2.0 增加安全比较器与主程序就绪看门狗。

## 发布顺序

1. 先发布并安装公开客户端 `1.2.0`。
2. 确认客户端能正常打开现有 V272 地图。
3. 将私有数据包中的 `manifest.json` 与 `production/map-data.json` 覆盖到 `SHmap-Data` 对应位置；保留 `submissions/` 和所有图片资源。
4. 提交并推送私有仓库。
5. 重新启动1.2.0客户端。程序会先建立 `pre_data_upgrade` 备份，再迁移到 `v282-r0001`。

## 迁移边界

- V282覆盖：正式名称、经篇、坐标、世界层级、证据状态、表2格位及电子表格官方字段。
- 本机保留：Markdown博物志、内部层级、图库、图片来源与版权、用户自建 `NEW` 对象、更改与历史归档。
- 同一R号产生的旧重复对象不继续带入V282。
- V282 manifest 要求最低客户端版本1.2.0；旧客户端会明确提示先更新，不会加载新数据。

## 验收

- 旧V272装饰背景停用，避免覆盖新四层空间。
- 升级后本机Markdown档案与图片仍存在。
